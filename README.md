# Flask + React Authentication App

This is a full-stack authentication system using Flask (Python) for the backend and React for the frontend.

## Features

- Signup with name, email, phone number, password
- Login with email and password
- Protected dashboard that shows user info
- JWT-based authentication
- CORS and secure API communication
- Professional-level structure and latest packages

## Setup Instructions

### Backend

```bash
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\\Scripts\\activate
pip install -r requirements.txt
python run.py
```
